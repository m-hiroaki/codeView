# 06 定義ジャンプ・参照探索

[索引](README.md) / 関連：[読取](03-files-tree.md)、[検索](05-search.md)、[本文移動](04-documents-tabs.md) / 上位：要件6章、基本設計6.4・6.5

## 1. 探索契約

`ISymbolNavigator`はNavigationに置く内部契約とし、画面は具体解析に依存しない。今回の実装は`SimpleSymbolNavigator`だけとする。

| 操作・型 | 入出力 |
| --- | --- |
| `FindDefinitionsAsync(request, writer, ct)` | 固定ルート・除外・文字コード、識別子、操作識別を受け、宣言候補と終了情報を返す |
| `FindReferencesAsync(request, writer, ct)` | 同じ情報を受け、参照一致を返す |
| `IdentifierQuery` | 元の選択範囲、比較用の名前、元の言語。元本文の参照を残さない |
| `DefinitionCandidate` | SearchHit相当の位置・抜粋、`Type / Delegate / Method / Property / Field`、簡易判定の情報 |
| `SymbolSearchRequest` | IdentifierQuery、ワークスペース条件、RequestId・WorkspaceEpoch・SearchEpoch |

定義の返却には`SearchEvent<DefinitionCandidate>`、参照には`SearchEvent<SearchHit>`を使い、05と同じ有界バッチ・ファイル確定・無効化・終了規則を適用する。候補に本文や全文トークン列を付けない。Operationsが候補数と全件評価の状態を見て自動移動を判断し、SimpleSymbolNavigator自身はタブを開かない。

## 2. 識別子の抽出

1. 選択がある場合、改行・空白・複数トークンを含まず1識別子であることを確認する。
2. 未選択ならカーソル位置のスカラー値を調べる。区切り直後では直前が識別子の末尾ならその語を採る。どちらにも属さなければ有効識別子なしとする。
3. Unicode文字・数字・結合文字等の構成規則は通常検索と共有し、先頭の数字を許可しない。C#の`@name`は元の選択範囲に`@`を含め、比較用からだけ除く。
4. C#予約語をそのまま指定した場合は識別子でないとして通知する。`@class`等は識別子として扱う。コンテキストキーワードは宣言位置で判断し、抽出だけで一律に拒否しない。
5. C#以外の定義は非対応を通知する。参照は有効な単語なら同じ名前照合を利用できる。

Unicode正規化や名前空間・ジェネリック引数の付加はしない。`obj.Method`全体の選択は拒否し、Method単体の選択を案内する。Unicodeエスケープで記述した識別子は初期版の保証対象外とし、通常表記と黙って同一視しない。

### 2.1 識別子抽出の実装（2026-11-07）

設計済みNavigation内の`IdentifierExtractor`で、供給された原文Spanから名前と元の範囲を得る。本文/UI型を参照せず、通常検索のRuneカテゴリを再利用する。先頭はUnicodeのLetter/LetterNumberまたは`_`、以降は通常検索の単語要素とする。最大4,096 UTF-16単位（`@`を除く）で、超過・不正範囲・サロゲート途中・空・複数語・エスケープ表記を拒否する。選択があればCaretより優先し、未選択では語の途中/直後/`@`上を扱う。C#予約語は`@`付きのみ許可し、文脈キーワードは抽出で拒否しない。正規化/大小文字変換は行わない。

NV-01の正常/異常/Unicode/上限を35単体ケースで確認。実装は既存設計の内部責務で、外部公開API・層・依存方向・本文データ構造を変更しない。明示要求時だけ有界走査し、起動/描画/常駐索引を追加しない。UI側の原文取得と参照検索の接続はP5-06で行う。定義解析・探索契約全体とG4/G5は未完了。

## 3. 簡易字句走査

対象は除外後の通常の`.cs`ファイルだけとし、厳格にデコードした文字チャンクから逐次トークンを得る。改行は位置に反映し、宣言の途中の改行は区切りにしない。全文AST・参照解決・プロジェクト索引を作らない。

| 状態 | 処理 |
| --- | --- |
| `Code` | 識別子・キーワード・記号・数値を読む。コメント・リテラル開始を判定 |
| `LineComment` | 改行まで候補判定から除外 |
| `BlockComment` | 終端まで除外し、終端未完なら解析未完了 |
| `String / Char` | バックスラッシュエスケープを含め終端まで除外 |
| `VerbatimString` | 二重引用符によるエスケープを扱って除外 |
| `RawString / InterpolatedString` | 終端規則を確認できる対応パターンだけ除外。安全に終端を認識できない場合は解析非対応として当該ファイルを未評価にする |

リテラル中の`class Foo`等をコードとして検出しない。補間文字列やraw文字列は単純に次の引用符まで読み飛ばす実装にしない。対応パターンと未対応の組合せはPhase 5の固定データで示す。不完全構文・非対応構文で文脈を復元できない場合は、誤った候補を確定せず当該ファイルを無効化する。

`#if`等の条件は評価せず両分岐を読むため、同名候補・非コンパイル対象の候補が含まれ得る。プリプロセッサー行を候補としては扱わない。字句処理の位置は元本文に対応し、コメント削除後の文字列上のオフセットを返さない。

保持は現在トークン、宣言用の有界な直前トークン列、括弧・型本体の文脈スタック、対象名と少量の抜粋に限定する。解析上限は[共通予算](01-contracts.md)のLexerTokenChars・DeclarationTokens・DeclarationChars・LexerDepthを参照する。超過は未評価として通知し、巨大な宣言を黙って欠落させない。Phase 5前に解析予算として固定する。

## 4. 宣言候補の検出

| 種別 | 初期対応の形 | 判定に使う文脈 |
| --- | --- | --- |
| 型 | `class N`、`struct N`、`interface N`、`enum N`、`record N`、`record class/struct N` | 名前トークンの完全一致。型の入れ子も文脈スタックで扱う |
| Delegate | `delegate ReturnType N(...)` | 戻り値の後の名前・引数列・終端 |
| Method | `ReturnType N(...) { ... }`、`=> ...;`、インターフェース等の`;`宣言 | 型本体直下。修飾子・属性・ジェネリック引数・制約を有界窓で読む |
| Property | `Type N { get; ... }`、`Type N => ...;` | 型本体直下で引数列のないメンバー形 |
| Field | `Type N;`、`Type N = ...;`、`Type A, N;` | 型本体直下。初期化式の括弧・波括弧で区切りを誤認しない |

メソッド・プロパティ・フィールドは、メソッド本体等の内部にいる場合は候補にしない。呼出し`obj.N()`やローカル変数は宣言扱いにしない。対象名の一部だけの一致は除外する。

コンストラクター、演算子、インデクサー、明示的インターフェース実装、ローカル関数、複雑な関数ポインター・新構文等は初期対応一覧に含めず、既知の精度制限として記録する。単純なメソッド・型の受け入れ要件は固定データで必ず確認する。構文の追加で全文ASTに拡大しない。

候補の位置は名前の開始。重複は同ファイル・同オフセット・同種別に限りまとめ、同名の別宣言は残す。候補確定のために必要なトークンの終端を待ってから返す。解析未完了で仮候補を返していた場合はFileInvalidatedで取り消す。

## 5. 完了と候補選択

| 状態 | 表示・操作 |
| --- | --- |
| 全件評価済み、候補1件 | その候補へ移動する |
| 全件評価済み、候補複数 | 「名前一致による宣言候補」の共用一覧を表示 |
| 全件評価済み、0件 | 「定義が見つかりません」 |
| 取消・上限・読取/解析の未評価あり | 部分結果を表示。1件でも自動移動しない。確定済み候補の明示選択は可能 |
| ルートや識別子なし | 実行せず必要条件を案内 |

「定義へジャンプ（簡易）」はコンパイラレベルの精度を保証せず、同名、オーバーロード、名前空間、継承、型推論は解決しない。未評価を含む0件は「見つからなかったが未評価あり」と表示し、完全な未検出と区別する。

## 6. 参照検索

SimpleSymbolNavigatorはIdentifierQueryの名前を、`MatchCase=true`、`WholeWord=true`、`UseRegex=false`の検索要求へ変換する。検索語の正規表現エスケープは不要で、正規表現そのものとして実行しない。

対象はルート内の全テキストファイル。宣言・コメント・文字列も含める。`@name`はnameで照合し、単語境界により`othername`等は除外する。一致位置は元本文のnameに対応し、必要に応じて補助表示で`@`も見せる。意味的な同一シンボルの参照であるとは表示しない。

## 7. テスト

| ID | 正常系 | 異常系・境界値 |
| --- | --- | --- |
| NV-01 | 選択・カーソル・`@name`・Unicode識別子 | 空、数字先頭、予約語、複数語、ドット列、語直後、エスケープ表記 |
| NV-02 | 型・delegate・method・property・field | コメント・文字列内の偽宣言、呼出し、ローカル、構文不完、宣言上限 |
| NV-03 | 複数行・ジェネリック・属性・record | 同名、入れ子、条件付き分岐、raw・補間リテラル、深さ上限 |
| NV-04 | 候補0・1・複数、明示移動 | 取消・部分失敗・上限で1件、自動移動禁止、旧候補の後着 |
| NV-05 | 参照の単語完全一致 | コメント・宣言も含む、部分一致除外、大小文字、CP932、結果位置 |

固定データには期待候補と既知の誤検出・見逃しを分けて記録する。単一の百分率だけでVisual Studio相当の精度を示さない。対応構文・制限は実装と同時に更新する。
