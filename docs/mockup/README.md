# codeView 外観・操作モック

[index.html](index.html)をブラウザーで開いて確認できます。HTML・CSS・JavaScriptを1ファイルにまとめており、サーバー起動、ビルド、ネットワーク接続は不要です。

## 確認できること

- 固定ダークテーマ、ファイルツリー、タブ、本文、検索結果、ステータスバーの配置
- ツリーの展開・折りたたみ、ファイル選択、タブ切替・閉鎖
- C#、C、C++、`.h`、JSON、Markdownのサンプル表示
- サンプル全体の検索、大小文字・単語単位・正規表現の切替、結果から該当行への移動
- ファイル内検索と次／前の一致への移動
- C#サンプルの簡易定義候補・参照一覧
- ツリー・結果パネルの表示切替、境界ドラッグによるサイズ変更
- メニューと主要ショートカット、空のタブ状態

初期画面は`OrderService.cs`と、`GetOrder`の検索結果を表示します。`native`内のファイルを選ぶとC/C++の外観を確認できます。`.h`はC++として表示します。

## モックの範囲

このモックは完成イメージを検討するためのもので、アプリ本体ではありません。ファイルを開く操作は同梱のサンプル選択へつながり、実際のローカルファイル・フォルダへのアクセスは行いません。サンプルコードも架空のものです。

構文色は簡易的な字句判定、検索・定義候補は少量のサンプルに対するデモ処理です。TextMate文法、厳格な文字コード判定、全言語の色分け、非同期I/O、大容量描画・検索の実装や性能を示すものではありません。文字コードはUTF-8固定の表示です。検索の逐次追加・キャンセルは画面状態のデモです。

実アプリの仕様は[基本設計書](../basic-design.md)と[詳細設計書](../detailed-design/README.md)を参照してください。モックの見た目や簡易処理を理由に、既存のアーキテクチャ・性能要件を変更しません。

## 検証

検索の文字列照合・サンプル結果・一致移動のロジックは、Node.jsがある環境で次のコマンドで確認できます。モックを開くためにNode.jsは必要ありません。

```sh
node --test docs/mockup/mockup.test.mjs
```

自動テストは実ブラウザーの描画試験ではありません。この作成環境ではブラウザーのセキュリティポリシーが`file:`の自動表示を拒否したため、実ブラウザーでの見た目・ドラッグ操作の確認は未実施です。
