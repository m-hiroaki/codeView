# P0-04-01 EventPipeの取得可否・負荷確認

P0-04の一部として、GC・LOHサンプル・Counterの取得と計測負荷を確認した。[記録](record.json)、[全8実行/80操作/トレース解析の圧縮JSON](runs.json.gz)、[Counter CSV](counters.csv)を保存する。再現手順は[計測手順](../../diagnostic-measurements.md)を参照する。

## 条件

macOS 27.0.1（26A434）、Apple M4/10物理・10論理コア、RAM 32 GiB、arm64、SDK 10.0.401、.NET 10.0.12。製品ソースはb274e81。Releaseの既存CorePerformanceTestsを一時ホストから直接呼び、50 MiB UTF-8（seed 20261106）の読取/構築/Snapshotを各10回実行する。入力はプロセス内で事前全読取しWarmにした。ほかのユーザーアプリが存在する通常環境であり、隔離した専用機ではない。

dotnet-trace/dotnet-counters 10.0.750501はartifactsの専用tool-pathへ導入した。解析はTraceEvent 3.1.23。製品/試験プロジェクトやカバレッジのtool manifestは変更していない。各ソース/バイナリ/入力と元のnettraceのSHA-256をrecord.jsonに記録する。元トレースはartifacts/diagnostics/comparisonへ保存し、Gitには圧縮した解析結果を収録した。

## 比較

各プロセス10操作の集計値。通常/gc-verboseはそれぞれ3プロセスの中央値、gc-collect/countersは1回の観測である。

| 条件 | 読込/構築合計 ms | CPU合計 ms | GC停止合計 ms | 対象ホストの標本最大footprint bytes |
| --- | ---: | ---: | ---: | ---: |
| 通常 | 4048.162 | 4669.793 | 809.015 | 310,330,304 |
| gc-collect | 4005.087 | 4636.022 | 806.390 | 311,804,888 |
| gc-verbose | 4087.305 | 4720.426 | 841.445 | 312,148,928 |
| counters | 4026.577 | 4705.015 | 818.307 | 313,312,240 |

gc-verboseの中央値差分は読込/構築+0.97%、CPU+1.08%、GC停止+4.01%、標本footprint+0.59%。少数の試行による今回の観測値で、普遍的なツール負荷ではない。gc-collect/countersの値が通常より小さい項目も速度改善とは扱わない。外部収集ツール自身のCPU/メモリはこの表に含まず、起動/終了を含むコマンド全体時間は別に保存した。

元のコア試験の5秒/512 MiB/GC合計150ms/ReadLease 50ms・1 MiBの各操作のassertを維持し、80操作はすべて終了0だった。1行のGC停止合計は10操作分であり、単一操作や単一GCの停止時間ではない。GUIの接続/スクロール/入力・Phaseの性能合格を意味しない。

## トレース/Counter

- 4トレースすべてでEventsLost 0、停止開始の重複/対応しない終了0、各10操作の20マーカーを確認した。
- GC理由の停止区間は各359〜360件。gc-verbose 3回の最大区間は20.851/7.510/7.059ms。全プロセスのトレースで、コアJSONの狭い計測窓と直接合算しない。
- 最終GCのLOH保持は131,152 bytes。gc-verboseは各1件のLarge:System.Byte[]のAllocationTickサンプルを捕捉した。サンプル件数/合計ObjectSizeを全LOH割当件数/量や生成元と読み替えない。スタックは未解析。
- CounterはJSTの4時刻・106行を取得。CPU時間Rate、working set、管理ヒープ/断片化、割当、GC世代別回数/停止時間等を確認した。TaskCanceledExceptionのカウンターには、試験用サンプラーの通常取消も含まれる。

操作マーカーはカスタムEventSourceのため動的パーサーで読む。最初の解析で拾えていなかった箇所を修正し、同じ保存済みトレースを再解析した。比較のための再収集はしていない。停止の対応不整合を検出する検査も加え、最終4トレースの解析はすべて終了0。

ホストの引数不足/0操作、解析器の存在しない入力/既存出力は終了2。既存の解析結果が変更されないこともハッシュで確認した。最初の試行用smokeは比較結果へ含めていない。

P0-04-01を完了し、記録テンプレート・取得可否・負荷の手順を残す。P0-04全体は、フレーム/物理I/O、Windows側の診断接続、LOH生成元等の残項目と計測基準機を確認するまで未完了。強制GCや新しい処理を通常製品へ導入していない。
