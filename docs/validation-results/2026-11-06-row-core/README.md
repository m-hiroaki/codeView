## 固定した評価範囲

メモリ上で50 MiB相当のASCII長行と49通常行を構築し、52,529,250 UTF-16単位から48行・16,384単位以内の投影を64回取得する。構築は計測外、アサーションは割当に含む。各OSで独立したテストプロセスを3回、直列実行した。既定予算は各取得50 ms以下、64取得の総割当4,194,304 bytes以下であり、緩和していない。v2の正確な50 MiB入力ファイル、I/O、描画や物理入力の測定ではない。

| 環境 | 総割当 bytes（各回） | 最大取得 ms（3回） | CPU ms（3回） | GC停止 ms（3回） |
| --- | ---: | --- | --- | --- |
| Windows CI | 3,255,720 | 3.7758 / 2.6553 / 2.6364 | 31.25 / 31.25 / 31.25 | 0 / 0 / 0 |
| macOS CI | 3,255,720 | 4.1697 / 1.2720 / 1.2647 | 22.933 / 13.136 / 14.358 | .542 / .506 / .599 |
| ローカルmacOS | 3,255,720 | .8912 / .8723 / .8484 | 9.087 / 8.963 / 9.157 | 0 / 0 / 0 |

すべて予算内。CIのmacOSは各回Gen0が1回、他は各世代0回。CPUはCPU使用時間であり使用率ではない。WindowsのCPU値は計時粒度の影響を受ける。メモリはWindowsのPrivateMemorySize64、macOSのphys_footprintの前後値を保存したもので、ピーク測定やOS間で直接比較できる指標ではない。これらをアプリ全体の起動・描画・検索・メモリ予算達成の根拠にしない。
