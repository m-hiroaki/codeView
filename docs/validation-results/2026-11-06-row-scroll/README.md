## 構築コスト

同じDocumentBuilderの最大行長取得OFF/ONを比較した。通常行は126単位+CRLFの409,600行（末尾空行を含め409,601行）、巨大1行は52,428,800単位。どちらもASCIIの50 MiB相当をメモリ上で16 Ki単位×3,200回追加する。ファイルI/O/デコードは含まない。各独立プロセスで各形状をABBAの4回計測外で事前実行し、AB/BA/ABの3組を測定した。各形状・各経路9サンプル/OSで、全記録を保持する。
