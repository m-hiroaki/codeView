# P1-05 設定待ちと共通Openの結合検証

2026-11-06、macOSのRelease通常単体630件合格、失敗/スキップ0、終了0。ローカルTRXは`artifacts/test-results/startup-settings/unit.trx`。Windows実行・GUI操作・起動性能の受入を意味しない。

## 今回の変更

- 内部のSettingsStoreへ既存ISourceAccessを任意に渡し、MainWindowViewModelへ.NET標準のTimeProviderを任意に渡せるようにした。通常は従来と同じSourceAccess/システム時計を使い、2秒の待ち上限を変更しない。
- 状態表示の設定失敗通知を共通Openのドレイン後へ移し、本文の読込/完了表示に直ちに上書きされないようにした。設定保存は引き続き未接続。原文・設定JSONへ書き込む処理は追加していない。
- 新規フレームワーク/レイヤ/外部公開API/設定項目・データ形式/常駐処理は追加しない。時計とI/Oの試験境界を既存責務へ限定した。

## 正常・異常・境界

`StartupSettingsIntegrationTests`の6ケースはUI相当の単一スレッドContextで実行する。設定ファイルのOpenをワーカー内で保留し、仮想タイマーを明示発火する。実時間の2秒待ちやSleepは使わない。

| 試験 | 確認内容 |
| --- | --- |
| CLI/メニュー/ドロップのFIFO | 設定待ち中はタブ0、3要求を受付順に一度だけ実行。設定成功後のタイマー/再初期化でも再実行なし |
| 時間超過と遅延成功 | タイマーへの指定が2秒で、UI外から期限発火→UI確定前のメニューOpenも受付順に実行。既定値/保存不可で確定後、遅い成功で入れ替えず元TaskをPendingWorkで追跡。設定Openは1回だけ |
| 設定待ち中の終了 | 待機要求を破棄し、以降のOpen拒否。取消不能Openが実終了するまではPendingWork未完了。終了後に本文やタブを復元しない |
| 時間超過後の終了 | 同じく元I/Oの実終了を追跡し、設定待ちタイマーを解放する |
| 遅延未知例外 | 時間超過後も元Taskを観測し、予期しない設定エラーをFatalFailureへ通知。既定値の二度目の確定に変換しない |
| 既知の読取失敗 | AccessDeniedを既定値/保存不可にし、読込済み本文と既定値通知を同時に維持 |

`StartupOpenQueueTests`に2ケースを追加し、256パスちょうどの受付、超過の全体拒否、実行中の予算維持、完了時だけの解放、空要求/不正入力元/257パスで予算が残らないことを確認した。既存試験で64要求ちょうど、256 Ki文字ちょうどと超過、不正パス、入力コピー、二重完了、停止後の遅い設定通知を確認している。既存Drop試験の転送寿命・混在入力・本文不変、契約/ファイル/検索/タブ等も今回の630件で回帰した。

確定直前のOpenの最初の試験では、仮想タイマーをUI上で発火させたため、継続がその場で進んで既にReadyとなり期待に失敗した。UI外のタイマー発火を待ってから、UI継続を実行する前の同じUIターンでOpenを投入する制御へ修正した。ワーカーはUI継続を待たずタイマー発火だけで返る。製品へ同期待機は追加していない。

## 性能・未実施

標準時計付きWaitAsyncは同じ2秒の期限と単一設定Taskを使う。追加I/Oや全文走査はなく、通知追加の文字列は設定失敗時だけ生成する。本文描画・検索経路は変更していない。標準APIは[MicrosoftのWaitAsync仕様](https://learn.microsoft.com/en-us/dotnet/api/system.threading.tasks.task.waitasync?view=net-10.0)に従う。

変更前後の空ウィンドウを各10回測定する比較も準備したが、変更前バイナリの最初の実行が`Avalonia.Native was not able to start the RenderTimer. Native error code is: -6661`で終了コード-6となった。[ログ](startup-unavailable.log)。Openedや結果JSONへ到達しておらず、今回の起動/CPU/メモリ/描画性能は未測定。設定待ち実装の回帰とも原因を確定せず、未測定を合格にしない。新しい専用GUIのビルドは警告0/エラー0。

P1-05の共通Openと設定待ち条件は満たした。P1-09の両OS起動10回、P3-06/P6のFinder/Explorer/IME等、P1-08の終了上限・異常終了受入やG1は残す。
