# 括弧色分け・対応ガイドの検証（2026-11-27）

macOS / .NET SDK 10.0.403 / Debug、既存Avalonia 12.1.3・AvaloniaEdit 12.0.0・TextMateSharp.Grammars 2.0.3で確認。新規依存なし。既存の文書所有権・レイヤ構成・公開APIは維持した。

## 実装・試験

- `()`・`[]`・`{}` の対応を深さ別の3色にし、複数行の組に同色のガイドを表示。
- 利用者の調整指示により、縦線・横線とも太さを **0.5 DIP** にした。
- 文法の文字列・コメント範囲を除外。混在括弧、Unicode、CRLF/CR/LF、不正な対応、空入力、最大組数32,768・最大深さ256の境界と、上限時にも通常の構文色が残ることを試験。
- 全体テスト：**1,302件合格、26件スキップ、失敗0件**。スキップは既存の環境依存・明示的実行の試験。[ログ](unit.log.gz)
- 実ウィンドウ：先頭・途中・末尾・横スクロールの描画、プレーン本文への切替時の解除、タブ復帰・再読込後の色変換/背景描画の重複がないことを確認。[GUIログ](gui.log)
- 表示範囲外から続く線、閉じ括弧、文字列・コメントの色を画像で確認。検証用ホストはMainWindowとFluent/AvaloniaEditテーマを使用し、ボタンのアプリ固有スタイルは読み込まないため、画像のボタン装飾は通常アプリと異なる。

## 性能影響

単一マシン・Debugの機構確認であり、製品全体の性能受け入れやリリース版のA/B比較ではない。

| 項目 | 観測・影響範囲 |
| --- | --- |
| CPU | 32,768組の解析・索引作成と問い合わせ1万回のCPU時間は合計14.070ms。プロセスのCPU時間差を使用し、CPU使用率の継続測定は未実施 |
| 解析 | 同条件の解析・索引作成11.396ms。一時割当3,933,264バイト。文法処理・文書構築はこの測定に含めない |
| メモリ | 最大組数時の保持配列は組24バイト×32,768＋区間索引4バイト×131,072＝約1.25MiB。構築用リストの容量は完了時に解放。プロセス全体のピークメモリは未測定 |
| 描画 | 最大組数の索引に対する表示範囲問い合わせ1万回2.709ms。実ウィンドウ末尾のガイド描画1,000回33.918ms・割当10,134,200バイト。後者はDrawingGroup生成・描画記録も含み、フレーム全体やGPU所要時間ではない |
| 起動 | 文法初期化や全文読取を追加せず、既存の本文表示後の遅延ワーカーで実施。初回本文の構文色が付くまでには追加解析コストがある。起動全体のA/B測定は未実施 |
| 検索 | 検索処理・検索用データ・ファイルI/Oの変更なし。描画・解析の追加CPU負荷は共有する。プロジェクト検索速度のA/B測定は未実施 |

本文2Mi UTF-16単位・1行8,192単位・解析5秒など既存の構文解析上限を維持。括弧の組数・深さの上限到達時は括弧色・線だけを破棄し、全件走査を描画時へ持ち込まない。文法が文字列と扱う補間式は対象外。Windows実機・DPI差の確認は未実施。

## 再実行

通常の単体試験：

```sh
dotnet test tests/codeView.Tests --no-restore -p:UsedAvaloniaProducts= -p:UseSharedCompilation=false -nodeReuse:false
```

`UsedAvaloniaProducts=` はビルドサービスのテレメトリログがサンドボックス外へ書き込まれることを避けるための実行時設定。テストランナーのローカルソケットとGUIの描画タイマーはサンドボックス外で実行した。オフラインでの一時ハーネス復元では `-p:NuGetAudit=false` を使用したが、リポジトリの設定や依存バージョンは変更していない。

[GUIハーネス](gui-harness.cs.txt) は一時実行用の記録。`/tmp/codeview-bracket-preview/Program.cs` に配置し、同ディレクトリのnet10.0実行プロジェクトでAssemblyNameを `codeView.Tests`、EnableDefaultCompileItemsをfalse、Compile対象をProgram.csだけにして本体csprojを参照する。設定・入力・画像は同一の一時ディレクトリ内に保存する。GUI検証は表示中のデスクトップセッションで実行する。
